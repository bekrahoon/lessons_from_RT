Объяснение кода

Словарь flags — хранит доменные имена стран и список цветов их флагов.
Пример: 'ru': ['red', 'blue', 'white'].

Бесконечный цикл while True — программа постоянно спрашивает у пользователя цвета.

Ввод пользователя — строка переводится в нижний регистр и разбивается на отдельные слова → превращается в множество (set).

Проверка совпадений — для каждой страны проверяем, входят ли введённые цвета в её флаг (issubset).

Если совпадают — страна добавляется в результат.

Вывод результата

Если есть совпадения → выводим список стран.

Если нет совпадений → пишем «Ничего не найдено».

Выход из программы — команда exit.
