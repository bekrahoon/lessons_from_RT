# 🎓 Telegram Бот для регистрации студентов

Telegram бот для регистрации студентов учебной группы с использованием SQLite3 и ООП.

## 📋 Возможности

- ✅ Регистрация студентов с 12 обязательными полями
- 📊 Просмотр информации о себе
- 👥 Просмотр списка одногруппников
- 📈 Статистика по студентам
- 🔐 Валидация всех вводимых данных
- 💾 Хранение данных в SQLite3
- 🏗️ Строгое использование ООП

## 📝 Поля регистрации (12 полей)

1. **Имя** - обязательное
2. **Фамилия** - обязательное
3. **Отчество** - обязательное
4. **Дата рождения** - с проверкой формата (ДД.ММ.ГГГГ)
5. **Номер группы** - обязательное
6. **Номер студенческого билета** - уникальное
7. **Номер телефона** - с валидацией
8. **Email** - с валидацией формата
9. **Специальность** - обязательное
10. **Курс** - от 1 до 4
11. **Адрес проживания** - опционально
12. **Контакт для экстренной связи** - обязательное

## 🏗️ Архитектура (ООП)

### Классы

#### database.py
- `DatabaseConnection` - управление подключением к БД (контекстный менеджер)
- `Student` - модель студента
- `StudentDatabase` - управление базой данных студентов

#### registration.py
- `RegistrationState` - enum для состояний регистрации
- `RegistrationSession` - управление сессией регистрации пользователя
- `RegistrationManager` - управление всеми сессиями регистрации
- `Validator` - валидация данных регистрации

#### bot.py
- `StudentRegistrationBot` - основной класс бота

## 🚀 Установка и запуск

### 1. Установите зависимости

```bash
pip install -r requirements.txt
```

### 2. Создайте бота в Telegram

1. Найдите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите токен
4. Скопируйте токен

### 3. Настройте токен

Откройте файл `bot.py` и замените:
```python
BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"
```
на ваш токен:
```python
BOT_TOKEN = "1234567890:ABCdefGHIjklMNOpqrsTUVwxyz"
```

### 4. Запустите бота

```bash
python bot.py
```

## 📱 Использование

### Команды бота

- `/start` - Начало работы с ботом
- `/register` - Начать регистрацию
- `/myinfo` - Просмотр своих данных
- `/group` - Просмотр списка одногруппников
- `/stats` - Статистика по студентам
- `/help` - Помощь
- `/cancel` - Отмена регистрации

### Процесс регистрации

1. Отправьте команду `/start` боту
2. Нажмите кнопку "✅ Начать регистрацию"
3. Последовательно введите все запрашиваемые данные:
   - Имя
   - Фамилию
   - Отчество
   - Дату рождения (формат: ДД.ММ.ГГГГ)
   - Номер группы
   - Номер студенческого билета
   - Телефон
   - Email
   - Специальность
   - Курс (1-4)
   - Адрес (или '-' для пропуска)
   - Экстренный контакт
4. Проверьте введенные данные
5. Подтвердите регистрацию



## 🗄️ База данных

База данных SQLite3 создается автоматически в файле `students.db`

### Структура таблицы `students`

| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER | Primary Key, автоинкремент |
| telegram_id | INTEGER | Уникальный ID пользователя в Telegram |
| first_name | TEXT | Имя |
| last_name | TEXT | Фамилия |
| patronymic | TEXT | Отчество |
| birth_date | TEXT | Дата рождения |
| group_number | TEXT | Номер группы |
| student_id | TEXT | Номер студенческого билета (уникальный) |
| phone_number | TEXT | Телефон |
| email | TEXT | Email |
| specialty | TEXT | Специальность |
| course | INTEGER | Курс |
| address | TEXT | Адрес |
| emergency_contact | TEXT | Экстренный контакт |
| registration_date | TEXT | Дата регистрации |

## 🔒 Валидация данных

Все поля проходят валидацию:

- **Имя/Фамилия/Отчество**: минимум 2 символа, только буквы
- **Дата рождения**: формат ДД.ММ.ГГГГ, возраст 16-60 лет
- **Телефон**: 10-12 цифр
- **Email**: стандартный формат email
- **Курс**: от 1 до 4
- **Студенческий билет**: уникальность
- **Telegram ID**: уникальность
